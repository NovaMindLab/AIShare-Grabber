## ⚡ How It Works (In 5 Seconds)

```
┌─────────────────────────┐          High-Speed Wi-Fi P2P         ┌─────────────────────────┐
│     Mobile Phone 📱     │ ────────────────────────────────────> │      PC / Mac 🖥️        │
│ (Scan QR / Auto-Wakeup) │        (Zero Cloud • 80+ MB/s)        │     (Local Storage)     │
└─────────────────────────┘                                       └────────────┬────────────┘
                                                                               │
                                                                               ▼
                                                                  ┌─────────────────────────┐
                                                                  │    Local AI Engine 🧠   │
                                                                  │ (100% On-Device Models) │
                                                                  └────────────┬────────────┘
                                                                               │
                                                                               ▼
                                                                  🔍 "golden retriever in snow"
                                                                  🔍 "sunset beach with cocktails"
                                                                  🔍 "restaurant receipt last week"
```

1. **Instant Wireless Pairing**: Open the companion app, scan the QR code on your desktop screen—or scan with your phone camera to automatically launch or download the client.
2. **Gigabit P2P Transfer**: Photos stream over your local Wi-Fi / WebRTC DataChannel at **80+ MB/s**. No cables, no bandwidth caps, no mobile data usage.
3. **100% Offline AI Indexing**: Desktop hardware (DirectML / CPU) extracts multimodal neural embeddings (MobileCLIP) & face vectors completely locally.
4. **Natural Language Search**: Find any photo instantly using everyday human descriptions—no manual tagging required.

## ✨ Key Features

<div align="center">
  <img src="./docs/images/ai_features.jpg" width="100%" alt="ShareCLIP AI Photo Management Features" style="border-radius: 12px; border: 1px solid rgba(255,255,255,0.1); box-shadow: 0 16px 40px rgba(0,0,0,0.5);" />
</div>

<br/>

### 1. ⚡ High-Speed Wireless P2P Sync
* **80+ MB/s Gigabit Speed**: Transfers 1,000 high-res photos in seconds over your local Wi-Fi network.
* **Zero USB Cables**: Forget searching for cables or toggling driver/MTP settings.
* **Zero Cellular Data**: Direct peer-to-peer transmission ensures not a single megabyte of mobile data is consumed.

### 2. 🔍 Multimodal Natural Language AI Search
* **Search Like You Speak**: Search for *"dog running on grass"*, *"sunset at the beach"*, or *"tax receipt"*—no manual tags or categories needed.
* **Apple MobileCLIP Multimodal Engine**: Maps queries and images into a unified 512-dimensional vector space with millisecond response time.
* **DirectML Hardware Acceleration**: Runs smoothly across discrete GPUs (NVIDIA/AMD), integrated graphics (Intel Iris/Xe), and multi-core CPUs.

### 3. 👥 Biometric Face Recognition & People Albums
* **Private Identity Clustering**: Cascaded **SCRFD 500M** face detection + **MobileFaceNet** ArcFace embeddings identify and group family members and friends.
* **Biometrics Never Leave Your Machine**: All face embeddings remain strictly on your physical device.

### 4. 🧹 Smart Duplicate & Burst Shot Cleanup
* **Zero-Copy SIMD Clustering**: Sub-second cosine similarity scans across thousands of photos to group duplicate shots and bursts.
* **Synchronized Dual-End Cleanup**: Trash blurry shots on your PC with a single click, and automatically purge the corresponding files on your phone.

### 5. 🗺️ EXIF Travel Footprint Map & Timeline
* **Interactive Geographic Map**: Automatically parses EXIF GPS data and plots your adventures on an interactive map.
* **Smooth Infinite Timeline**: Fluid 60 FPS virtual scroll handling libraries with 50,000+ photos effortlessly.

### 6. 📱 Smart Mobile Deep Linking & Web Fallback
* **Seamless QR Routing**: Scan the desktop QR code using your phone's default browser—if ShareCLIP is installed, it deep-links directly via `shareclip://open`; if not, it falls back to the smart download landing page with zero friction.
* **Zero-Install WebShare**: Instant ad-hoc transfers in modern browsers via WebRTC without installing any software.

### 7. 🎵 Cyber Hi-Fi Ambient Radio & YouTube Sniffer
* **Built-in Media Downloader**: Integrated with `yt-dlp` for downloading high-fidelity audio/video resources into your local library.
* **Cyberpunk Radio Station**: Ambient focus music and Lo-Fi streams built directly into your gallery workspace.

## 🧠 Technical Architecture

For developers, architects, and AI practitioners looking under the hood:

```mermaid
flowchart LR
    subgraph Mobile [Android Companion / WebShare]
        A[MediaStore / PhotoManager] -->|Concurrent Extraction| B[400x400 Thumbnail Stream]
        B -->|Chunked 16KB-32KB Binary Frames| C[WebRTC DataChannel]
    end

    subgraph Desktop [PC Host Electron]
        C -->|Rapid Disk Write| D[Local Isolated Storage]
        D -->|Task Queue Dispatch| E[ONNX Worker Pool]
        
        subgraph AI_Engine [On-Device AI Acceleration]
            E -->|MobileCLIP-S0 256x256| F[512-D Image Embedding]
            E -->|SCRFD + MobileFaceNet| G[Face Biometric 512-D]
            F & G -->|Lock-Free Single Writer| H[(SharedArrayBuffer 40MB-200MB)]
        end
        
        H -->|Zero-Copy SIMD Dot Product| I[Sub-Millisecond Cosine Search]
        I --> J[Vue 3 60fps Virtual Timeline]
    end
```

### Key Architectural Highlights
* **Lock-Free SharedArrayBuffer Memory Sharing**: Eliminates Node.js IPC serialization overhead by mapping 512-D embeddings directly into shared memory. Cosine clustering across 5,000 photos completes in **~120ms**.
* **16-Byte Binary Protocol Framing**: Fixed header protocol (`fileId`, `chunkIndex`, `totalChunks`, `payloadLength`) handles high-concurrency streaming with adaptive backpressure flow control.
* **DirectML ➔ CPU Auto-Fallback**: Ensures rock-solid reliability across NVIDIA, AMD GPUs, and Intel CPU configurations.

## 💻 Developer Guide

### Monorepo Structure
```
AIShare-Grabber/
├── 📱 android/      # Flutter Android Companion App (BLE GATT + WebRTC DataChannel)
├── 🖥️ cp_clip/      # Desktop Host App (Electron 30, Vue 3, ONNX Runtime, SQLite, Sharp)
│   ├── src/workers/ # Worker Thread Pool (Search, SIMD WASM clustering, ONNX Inference)
│   └── models/      # Quantized MobileCLIP-S0 & Buffalo_SC ONNX models
├── 🌐 web/          # Official Portal & Interactive Download Landing Page
├── ⚡ webshare/     # Pure Web Client (WebGPU + WebRTC P2P + IndexedDB)
├── 📦 manifests/    # Package manager manifests (WinGet, Scoop, Homebrew)
└── 📖 wiki/         # Comprehensive Architecture & Protocol Documentation
```

### 1. Android Mobile Client
```bash
# Prerequisites: Flutter SDK >= 3.11.1 & Android SDK
cd android
flutter pub get
flutter run --release
```

### 2. Desktop PC / Mac Client
```bash
# Prerequisites: Node.js >= 20, Python >= 3.10
cd cp_clip
npm install

# Run in Development Mode
npm run dev

# Package for Distribution
npm run dist
```

### 3. Official Web Portal
```bash
cd web
npm install
npm run dev
```
