# NovaMindLab Scoop Bucket

A [Scoop](https://scoop.sh/) bucket for NovaMindLab applications.

## Installation

### 1. Add the bucket and install

```powershell
scoop bucket add novamindlab https://github.com/NovaMindLab/scoop-bucket
scoop install shareclip
```

### 2. One-line direct install (no bucket required)

```powershell
scoop install https://raw.githubusercontent.com/NovaMindLab/scoop-bucket/main/bucket/shareclip.json
```

## Available Apps

| App | Description |
|-----|-------------|
| `shareclip` | Private P2P AirDrop Alternative & Local AI Photo Gallery |

## About ShareCLIP

ShareCLIP is a privacy-first, local-network file transfer tool and on-device AI photo gallery.  
No cloud. No sign-up. Just seamless sharing.

- **P2P Transfer** — AirDrop-style file sharing over LAN between any devices
- **AI Photo Search** — On-device MobileCLIP semantic photo search, zero cloud reliance
- **Cross-platform** — Windows, macOS, Android
