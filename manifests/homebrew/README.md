# NovaMindLab Homebrew Tap

A [Homebrew](https://brew.sh/) tap for NovaMindLab applications.

## Installation

### 1. Add the tap and install

```bash
brew tap NovaMindLab/homebrew-tap
brew install --cask NovaMindLab/homebrew-tap/shareclip
```

### 2. Direct one-line install (no tap required)

```bash
brew install --cask https://raw.githubusercontent.com/NovaMindLab/AIShare-Grabber/main/manifests/homebrew/shareclip.rb
```

## Uninstallation

```bash
brew uninstall --cask shareclip
```

To also remove the tap:

```bash
brew untap NovaMindLab/homebrew-tap
```

## About ShareCLIP

ShareCLIP is a privacy-first, local-network file transfer tool and on-device AI photo gallery.  
No cloud. No sign-up. Just seamless sharing.

- **P2P Transfer** — AirDrop-style file sharing over LAN between any devices
- **AI Photo Search** — On-device MobileCLIP semantic photo search, zero cloud reliance
- **Cross-platform** — Windows, macOS, Android
