### 一、80MB/s 局域网极速直传：AirDrop 终于有了跨端终极替代方案

> [插图建议：手机扫码后，4K 视频进度条毫秒级拉满，桌面端即刻弹出的动图/照片]

ShareCLIP 的传输底层彻底摒弃了第三方云中转服务器，而是**纯粹基于本地 WebRTC DataChannel 与 UDP 局域网广播（15185 端口）**：

- **真·千兆满速直传**：手机与电脑处于同一 Wi-Fi（或手机开热点电脑直连），实测原画 4K 视频直传速度可稳定在 **50~85 MB/s**。几十张几十兆的 RAW 原图基本是一瞬间闪过。
- **免装 App 的 WebShare 网页端**：朋友来家里玩，想传几十张聚会合照，根本不用让对方特地下载安装 App。电脑端点击生成二维码，朋友用 iPhone 或任意手机浏览器扫码，浏览器通过 WebRTC 就能直接建立 P2P 接收通道。
- **完全断网可用**：户外自驾、飞机高铁上即便没有互联网，只要两台设备连在同一个随身 Wi-Fi 或热点上，就能自由极速互传。

### 二、100% 离线本地 AI 搜图：把你的沉睡相册彻底“盘活”

> [插图建议：搜索框输入“雪山下的红色汽车”，本地瞬间秒出对应照片的检索界面截图]

这是 ShareCLIP 区别于市面上所有纯传输工具（如 LocalSend）的核心王牌功能。

市面上常见的相册分类往往依赖大厂云端接口，但把相册交给公网 API 既有严重的隐私顾虑，调用成本也无法承受。ShareCLIP 选择将 **Apple 官方最新的端侧轻量视觉模型 MobileCLIP2-S0** 完整内嵌到了桌面端（基于按需裁剪至 18.2MB 的 ONNX Runtime 引擎）。

#### 1. 真正的“自然语言具象搜图”
导入相册后，引擎会在本地异步提取每张照片的 512 维特征向量，常驻内存仅约 90MB。建立索引后，你可以直接用你平时说话的习惯进行搜索：
- 输入 `“戴草帽在海边喝椰汁”`
- 输入 `“餐馆的纸质收据发票”`
- 输入 `“下雨天的霓虹灯街道”`

无需手动打标签，毫秒之间，相册中对应场景的照片就会精准呈现在眼前！

#### 2. 本地人脸聚类与足迹地图
- **智能人物相册**：内置 SCRFD 500M 超轻量人脸检测与 MobileFaceNet，本地执行两阶段 HAC 聚类，自动将你相册里的家人、伴侣、朋友归纳成独立的人脸相册，连谁眨眼、谁笑了都能清晰识别。
- **离线足迹地图**：自动解析照片 EXIF 中的 GPS 经纬度，在内嵌的离线地球上以热力聚类展现你的旅行足迹。

最关键的是：**所有向量提取、模型推理全部在你的 CPU / DirectML 本地显卡上跑完，拔掉网线照样秒级检索，绝对零云端泄露风险！**

### 三、极客专属：4K 多平台视频下载与独立弹窗播放器

很多朋友平时喜欢在 B站、YouTube、小红书等平台收藏优质教程或 4K 实拍片段。ShareCLIP 深度集成了 `yt-dlp` 内核与便携 FFmpeg 探针：

- **一键解析下载**：粘贴链接即可自动嗅探 4K HDR 原画、独立音频流并静默合并封装，自动压入原封面与元数据；
- **自研无边框画中画播放器**：支持基于 HTTP 206 Range 的局部毫秒级流式预览，不用等整个大视频下完即可随点随播，支持全键盘快捷键操控与置顶画中画悬浮。

### 四、全平台适配与安装指南

ShareCLIP 采用 MIT 协议开源，无广告、无内购、无任何遥测后门，现已登录主流包管理器：

* **Windows 用户（首选命令行或微软商店）**：
  ```powershell
  winget install NovaMindLab.ShareCLIP
  ```
  *(亦可在 Windows 微软自带的 Microsoft Store 搜索 `ShareCLIP` 一键安装)*
* **macOS 用户（双架构支持 Apple Silicon M系列与 Intel）**：
  ```bash
  brew install --cask shareclip
  ```
* **Android 手机端**：
  直接在 GitHub Releases 或 F-Droid (IzzyOnDroid) 获取 Universal signed APK。
* **纯网页版体验**：
  无需安装，浏览器直达在线 WebShare：`https://novamindlab.github.io/AIShare-Grabber/webshare/`
