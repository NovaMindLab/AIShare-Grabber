## ⚡ So funktioniert es (in 5 Sekunden)

```
┌─────────────────────────┐          High-Speed Wi-Fi P2P         ┌─────────────────────────┐
│     Mobile Phone 📱     │ ────────────────────────────────────> │      PC / Mac 🖥️        │
│ (Scan QR / Auto-Wakeup) │        (Zero Cloud • 80+ MB/s)        │     (Local Storage)     │
└─────────────────────────┘                                       └────────────┬────────────┘
                                                                               │
                                                                               ▼
                                                                  ┌─────────────────────────┐
                                                                  │    Local AI Engine 🧠   │
                                                                  │ (100% On-Device Models) │
                                                                  └────────────┬────────────┘
                                                                               │
                                                                               ▼
                                                                  🔍 "golden retriever in snow"
                                                                  🔍 "sunset beach with cocktails"
                                                                  🔍 "restaurant receipt last week"
```

1. **Sofortige drahtlose Kopplung: QR-Code auf dem PC-Bildschirm mit dem Smartphone scannen.**
2. **Gigabit-P2P-Übertragung: Direkter Fototransfer über lokales WLAN mit 80+ MB/s ohne Mobilfunkverbrauch.**
3. **100% lokale KI-Indizierung: Lokale Hardware verarbeitet MobileCLIP- und Gesichtserkennungsmodelle.**
4. **Suche in natürlicher Sprache: Beschreiben Sie einfach, was Sie suchen, um Fotos sofort zu finden.**

## 🚀 Installation und Schnellstart

### 📦 Quick Install via Package Managers

#### Windows (WinGet / Scoop)
```powershell
# Install via official WinGet
winget install NovaMindLab.ShareCLIP

# Or install via Scoop
scoop bucket add novamindlab https://github.com/NovaMindLab/scoop-bucket
scoop install shareclip
```

#### macOS (Homebrew Cask)
```bash
# Direct install via Homebrew Cask
brew tap NovaMindLab/homebrew-tap
brew install --cask shareclip
```

## 🧠 Technische Architektur

```mermaid
flowchart LR
    subgraph Mobile [Android Companion / WebShare]
        A[MediaStore / PhotoManager] -->|Concurrent Extraction| B[400x400 Thumbnail Stream]
        B -->|Chunked 16KB-32KB Binary Frames| C[WebRTC DataChannel]
    end

    subgraph Desktop [PC Host Electron]
        C -->|Rapid Disk Write| D[Local Isolated Storage]
        D -->|Task Queue Dispatch| E[ONNX Worker Pool]
        
        subgraph AI_Engine [On-Device AI Acceleration]
            E -->|MobileCLIP-S0 256x256| F[512-D Image Embedding]
            E -->|SCRFD + MobileFaceNet| G[Face Biometric 512-D]
            F & G -->|Lock-Free Single Writer| H[(SharedArrayBuffer 40MB-200MB)]
        end
        
        H -->|Zero-Copy SIMD Dot Product| I[Sub-Millisecond Cosine Search]
        I --> J[Vue 3 60fps Virtual Timeline]
    end
```
